# Security policy

Ponytail Amp is an experimental, independent plugin adaptation. It is not an official Amp or upstream Ponytail security channel, and it makes no security guarantee for Amp or for code it guides an agent to write.

## Reporting a vulnerability

Please do not post exploit details, proof-of-concept code, secrets, or sensitive logs in a public issue or pull request. First check whether private vulnerability reporting is enabled in this repository's GitHub **Security** interface and use that private route if available. If it is not enabled, request a private reporting channel through a contact route available from the repository or maintainers; do not disclose the vulnerability publicly while waiting for a private channel.

Do not include credentials or customer data in a report. Share only the minimum reproduction details needed for a private investigation. There is no security email address or response-time commitment specified by this project.

## Scope notes

The plugin is intended to register skills and inject hidden development guidance in Amp. It does not intentionally alter Amp settings, select a model or agent, change permissions, install `AGENTS.md`, or download runtime dependencies. These design statements are not a completed security audit. Archive checksums are integrity checks, not signatures and not proof of publisher identity.
